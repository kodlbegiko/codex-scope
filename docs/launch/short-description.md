# Short descriptions

## One sentence

Codex Scope is a deterministic, read-only CLI that explains which supported Codex instructions and config win, where they came from, why they won, and what remains unresolved.

## Short repository / community description

Know which Codex instructions and config win before you start a session. Codex Scope resolves the supported AGENTS/config layers with provenance, winner/shadowed state, and explicit uncertainty — without an LLM, API key, or hook execution.

## Scope boundary

Codex Scope is an independent community project. It models an explicitly documented/tested subset of Codex behavior and does not replace native Codex runtime diagnostics or claim full compatibility.
