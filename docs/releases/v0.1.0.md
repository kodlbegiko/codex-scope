# Codex Scope v0.1.0

First public release of Codex Scope, an unofficial deterministic inspector for the Codex instruction chain and supported configuration precedence.

## Highlights

- `codex-scope inspect` — concise effective-environment overview.
- `codex-scope instructions` — AGENTS discovery, ignored sources, byte limits, and provenance.
- `codex-scope config` — supported configuration precedence with explicit uncertainty.
- `codex-scope why <key>` — one decision chain with winner, shadowed, ignored, conditional, and missing inputs.
- Versioned JSON output for all four core commands.
- Centralized secret redaction and fail-closed parsing.
- Deterministic fixtures and conformance-oriented regression tests.

## Safety properties

Inspection performs no LLM calls, requires no OpenAI API key, has no runtime network dependency, executes no discovered hooks, and does not mutate the inspected configuration or project.

## Compatibility boundary

V0.1.0 intentionally models a documented subset of Codex behavior. Hooks, MCP, plugins, snapshots, directory diffs, managed enterprise constraints, and the full Codex config schema are not claimed as supported. See `docs/compatibility.md` and `docs/semantics.md`.
