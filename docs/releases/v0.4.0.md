# Codex Scope v0.4.0

Codex Conformance Observatory and a bounded OpenCode offline adapter, while preserving the existing Codex-facing CLI.

## Codex Conformance Observatory

- Expand the Codex corpus to 50 evidence-backed semantic cases and five regression/change records.
- Retain three upstream evidence snapshots without rewriting historical evidence.
- Generate machine-readable compatibility history and classify cross-snapshot drift, including explicit evidence gaps and tool failures.
- Record an upstream finding and a maintainer-facing source-level recheck without claiming an unperformed binary reproduction.

## OpenCode adapter

- Add a bounded, read-only OpenCode adapter for explicitly supplied inert state.
- Pin 31 semantic rules and three upstream regression/change records with compatibility and false-certainty gates.
- Keep remote configuration, live session state, hooks, plugins, MCP execution, and outside-evidence revisions unresolved or unsupported.
- This adapter is an internal conformance surface, **not** a new public OpenCode CLI command.

## Compatibility and safety

- The existing `inspect`, `instructions`, `config`, `why`, and `compatibility` commands remain Codex-facing.
- The `codex-scope.v0.1` JSON contract is unchanged. Observatory artifacts are additive and separately versioned.
- Inspection remains deterministic and read-only, with no LLM calls, runtime network access, agent binary execution, hook/plugin/MCP execution, or inspected-repository mutation.
- Phase D's Codex/Gemini comparison remains an unreleased Draft PR. Its independent external-user proof gate is still 0/3; v0.4.0 does not include a public `compare` command.
