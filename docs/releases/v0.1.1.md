# Codex Scope v0.1.1

Compatibility and onboarding hotfix for the first public release.

## Fixed

- `$CODEX_HOME` is no longer loaded a second time as a project `.codex` configuration layer. This matches current Codex behavior and avoids false project-trust uncertainty when running from the home directory.
- Added regression coverage for home-directory invocation and for `$CODEX_HOME` located inside a project tree.
- Corrected the no-install command to:

```bash
npx --yes --package=codex-scope-inspector codex-scope inspect
```

## Package

npm package: `codex-scope-inspector@0.1.1`

CLI command: `codex-scope`
